🌾 MANDIMITHRA AI – Smart Mandi Intelligence & Farmer Profit Companion

📌 Project Overview

MANDIMITHRA AI is an AI-powered agricultural intelligence platform designed to help farmers make smarter and more profitable decisions. It provides crop-specific market insights, mandi price comparisons, price trend forecasts, storage recommendations, and government scheme assistance through a single, user-friendly platform.

Agricultural prices fluctuate frequently due to changes in demand, supply, seasonal conditions, and market trends. Farmers often struggle to identify the right time and place to sell their produce. MANDIMITHRA aims to bridge this information gap by providing intelligent insights and personalized agricultural assistance.

The platform supports multiple Indian languages, making agricultural information more accessible to farmers across different regions.

 🎯 Key Features

1. 📊 Smart Mandi Dashboard
- Search and analyse different agricultural crops.
- Compare mandi prices across different markets.
- View mandi rankings based on estimated net profit.
- Calculate transportation costs and estimated payouts.
- Analyse crop quantity, size, and quality grades.

2. 📈 AI-Based Price Forecasting
- View historical price trends.
- Explore upcoming five-day price forecasts.
- Identify potential price increases or decreases.
- Receive suggestions on whether to sell immediately or wait.
- View estimated profit and loss based on crop shelf life.

 3. 🔔 Smart Price Alerts
- Set target prices for agricultural produce.
- Receive notifications when simulated prices increase.
- Monitor price movements through the alert centre.
- Enable browser notifications for price alerts.

 4. 🤖 Mithra Kisan – AI Farmer Chatbot
- Interactive AI-powered farming assistant.
- Ask questions about crops, mandi prices, irrigation, pests, and storage.
- Supports text-based and voice-based interaction.
- Provides multilingual responses.
- Includes voice-note transcription and AI-generated replies.

5. 🏛️ Yojana Mithra – Government Scheme Assistant
- Explore agricultural loans and government schemes.
- Browse subsidies, crop insurance, and infrastructure support.
- View eligibility criteria and required documents.
- Get AI-based scheme recommendations based on land size, crop, location, and farming requirements.

6. 📰 Mandihut – Agricultural News & Updates
- Agricultural market and MSP updates.
- Weather and monsoon-related information.
- Agricultural technology and storage updates.
- AI-generated daily agricultural briefings.

 7. 🌐 Multilingual Support
The platform supports three languages:
- English
- Kannada
- Hindi

This helps farmers access agricultural information in a language they understand.

## ⚙️ How It Works

1. Farmers enter their name, mobile number, locality, and preferred language.
2. They select an agricultural crop and provide its quantity and grade.
3. The dashboard analyses available crop and market information.
4. Farmers can compare mandi prices and explore estimated profit opportunities.
5. The AI assistant answers agricultural questions.
6. Yojana Mithra helps farmers discover potentially relevant government schemes.
7. Price alerts help farmers monitor changes in the application's estimated market prices.

🚀 Installation and Setup

Prerequisites
- Node.js
- npm or Bun
- Google Gemini API key
- VS Code (recommended)
 Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

Step 2: Open the Project

```bash
cd agriculture-main
```

 Step 3: Install Dependencies

```bash
npm install
```

 Step 4: Configure Environment Variables

Create a `.env` file in the root directory and add:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Get your API key from Google AI Studio.

 Step 5: Run the Application

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

### Step 6: Build for Production

```bash
npm run build
```

MANDIMITHRA combines agricultural market intelligence, AI-powered farming assistance, price forecasting, storage guidance, and government scheme discovery into one multilingual platform.

Instead of simply displaying market prices, it aims to help farmers understand market trends, compare selling opportunities, reduce post-harvest losses, and make informed decisions.
